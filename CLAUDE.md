# @tma.js

- The project's goal is to be a better alternative to the official Telegram Mini Apps SDK,
  [telegram-web-app.js](https://telegram.org/js/telegram-web-app.js). When adding or changing
  platform functionality, check the official SDK's implementation to keep feature parity.
- The official platform documentation is https://core.telegram.org/bots/webapps. Use it, together
  with the official SDK's source, as the source of truth for how methods and events work.
- Documentation source lives in `apps/docs` and is published at
  https://docs.telegram-mini-apps.com/. Update it when the public API changes.
- Contribution rules, philosophy and the check commands are in @CONTRIBUTING.md.
- AI attribution is forbidden. Don't add `Co-Authored-By` trailers, "Generated with" lines or any
  other mention of AI tools to commits, pull requests, issues, code or documentation.
